# Fresh Bloom GitHub Pages website

Responsive static storefront for Fresh Bloom, built from the supplied cosmetics documentation. It uses HTML, CSS and vanilla JavaScript with no build step.

Features include a premium responsive homepage, PKR product catalog, search, filters, sorting, wishlist and bag interactions, mobile navigation, newsletter feedback, and a GitHub Actions Pages deployment workflow.

Enable deployment in Settings → Pages → Source: GitHub Actions. The expected URL is:

`https://valeejahshahid2030-code.github.io/cosmetics/`

The catalog and contact information are sample configurable data. Connect checkout, authentication, orders and a trusted payment gateway to a secure backend before accepting live payments. This static site never collects or stores card details.
